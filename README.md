# AI-BOT-DAS009332 - AI Registration Assistant

## Project Description
This is an AI-based conversational chatbot for intern registration, developed as part of Data Alcot Systems Internship Task 1.

The bot collects:
- Full Name
- Email Address
- Field of Interest
- Experience Level
- Intern ID: DAS009332

## Features
- Validates email format
- Saves data in registrations.json
- Simple and user-friendly CLI interface
- Built with Python

## How to Run
1. Install Python 3
2. Run: python chatbot.py
3. Follow instructions to register

## Tech Stack
- Python
- JSON for storage
- Regex for validation
